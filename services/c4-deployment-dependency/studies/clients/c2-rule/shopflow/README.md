# ShopFlow

Generated by the AI driven SDLC platform: the API contract was inferred from the wireframes and the architecture graph, and both sides of this monorepo were generated from that contract.

- Design version: v1
- Contract arm: rule
- `apps/web`: the frontend (React 19 + Vite + TypeScript)
- `apps/api`: the backend (Express 5 + TypeScript)
- `packages/contract`: the shared types and the typed client, the one source both sides agree through

## Running it

One process serves both sides: the API also serves the built frontend,
so there is one port and one URL.

```
npm install
npm run build      # builds apps/web into apps/web/dist
npm start          # serves the API and that build on PORT (default 3001)
```

Then open http://localhost:3001.

`HOST` defaults to 0.0.0.0 so a container can reach it. Set
`HOST=127.0.0.1` to keep it on this machine.

While working on it, run the two sides separately in two terminals:
`npm run dev:api` and `npm run dev:web`. The web dev server proxies the
API's routes, so the frontend calls its own origin either way.

```
npm run typecheck
npm test
```

The repositories are in memory, so the data starts empty and resets
when the process restarts.
